This is my entry for the make.fun bounty "The Houseplant Out of Office": an out-of-office reply written by a houseplant. The plant has no hands, no inbox, and no intention of replying — it just wants to be watered.

`main.py` writes the reply to `/output/entry.txt`. The program is deterministic — it produces the same bytes on every run — and it uses only the Python standard library, with no network access.
